# Tools & Agents

**Priority:** P0  
**State:** proposed  
**Lead:** Unassigned  
**Release decision:** headline

Select and call tools such as search, code execution, and file operations; interpret observations; recover from errors; and respect permissions.

**Model promise:** Complete useful tool-mediated tasks reliably in target languages without inventing tool results or exceeding authority.

## Training route

- function-calling SFT
- execution-grounded trajectories
- tool-verifiable RL
- permission and recovery repair
