# Multilingual

**Priority:** P0  
**State:** proposed  
**Lead:** Unassigned  
**Release decision:** regression-protected

Useful model behavior across 36 OpenEuroLLM language identities represented by 37 release locales, with three explicitly measured investment tiers.

**Model promise:** Deliver broad European-language utility while keeping each tier within ten percent of the preceding tier on normalized capability scores.

## Training route

- base coverage audit
- target-language SFT and preference data
- weak-language repair
- native-speaker review
