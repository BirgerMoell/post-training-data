# Instruction & Chat

**Priority:** P0  
**State:** proposed  
**Lead:** Unassigned  
**Release decision:** headline

Follow explicit and implicit instructions, sustain useful multi-turn dialogue, and produce constrained outputs in all target languages.

**Model promise:** Reliably do what the user asks, preserve constraints across turns, and recover cleanly from ambiguity or tool failure.

## Training route

- broad instruction SFT
- multilingual instruction repair
- preference optimization
- format and multi-turn regression repair
