# Coding

**Priority:** P2  
**State:** proposed  
**Lead:** Unassigned  
**Release decision:** diagnostic

Generate, repair, and execute code, with dedicated reinforcement learning only after ownership and contamination controls are established.

**Model promise:** Produce correct, testable, secure code and use coding tools without regressing multilingual instruction behavior.
